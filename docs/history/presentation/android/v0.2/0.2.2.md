## [v0.2.2] - 2026-07-24

### 新增功能 (Added)
* 新增 `Query` 页面的跨月范围 (Range) 查询模式，支持自定义选择起止年月（如 `2025-01` 至 `2025-06`）并生成跨月对比报表。
* 新增 `YearMonthPickerSheet` 底部年月选择弹窗组件 (`apps/bills_android/src/main/java/com/billstracer/android/features/common/YearMonthPickerSheet.kt`)，支持根据实际账单动态高亮与快速选取。
* 新增 `RangeStandardReportCards` 与 `RangeStandardReportParser`，用于解析与渲染跨月范围报表 UI 卡片。
* 新增 `QueryInputModePreferenceStore` 数据持久化 (`apps/bills_android/src/main/java/com/billstracer/android/data/prefs/QueryInputModePreferenceStore.kt`)，自动记住并恢复用户偏好的查询模式 (Monthly / Yearly / Range)。
* 新增 `RawTextEditText` 原生文本输入框组件 (`apps/bills_android/src/main/java/com/billstracer/android/features/editor/RawTextEditText.kt`)，提升 Raw TXT 模式大文本编辑流畅度。

### 技术改进/重构 (Changed/Refactor)
* 重构 Android JNI 交互桥梁 `apps/bills_android/src/main/cpp/query_bridge.cpp` 与 `QueryNativeBindings.kt`，接入 C++ 原生 `RangeQuery` 区间查询与范围数据转换接口。
* 重构 `QueryViewModel` 与 `QueryScreen` 架构，统一单月、年度与跨月范围模式的控制流与卡片组装逻辑。
* 更新 `apps/bills_android/build.gradle.kts` 中 Android 表现层版本号至 `0.2.2` (versionCode `3`)。

### 修复 (Fixed)
* 修复查询模式在应用重新加载后自动回退至单月模式的问题，实现用户查询偏好无缝持久化。
* 修复跨月查询结果卡片中月度明细列表由于缺少区间格式支持而无法准确呈现各月收支汇总的问题。
