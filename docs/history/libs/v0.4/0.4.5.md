## [v0.4.5] - 2026-04-11

### 新增功能 (Added)
* 新增 `libs/core/src/record_template/record_editor_service.*` 与 `libs/core/src/record_template/record_editor_types.hpp`，提供面向 Editor 的记录结构模型以及 `TXT <-> 结构文档` 解析/序列化能力。
* 新增 `bill.core.record_editor.types` 与 `bill.core.record_editor.service` 模块导出，供 Android 等上层编辑器复用统一的 `date:`、`remark:`、父标题、子标题识别规则。
* 新增 `backup bundle` 对 `export_formats.toml` 的正式支持，使 `workspace snapshot` 可同时携带 `validator_config.toml`、`modifier_config.toml` 与 `export_formats.toml` 进行跨设备恢复。

### 技术改进/重构 (Changed/Refactor)
* 重构 Editor 结构识别边界，将标题骨架解析从 Android 端下沉到 `libs/core`，为“结构锁定的记账编辑器”提供共享基础能力。
* 明确 `record editor` 解析链路的设计意图与边界注释，使其与 `ingest` 导入解析器的职责区分更清晰，避免编辑场景误复用导入期自动整理行为。
* 重构 `libs/core/src/ingest/transform/bills_parser.cpp`，改为复用 `content_line_support` 解析金额表达式、描述与注释，使导入链路与结构锁定编辑器共享同一条内容行语义。
* 重构 `libs/io/src/io/host_flow_support.cpp` 的 `backup bundle` manifest、装载与写回流程，统一 `workspace snapshot` 的导出与恢复格式。

### 修复 (Fixed)
* 修复 `backup bundle` 之前拒绝 `config/export_formats.toml` 的问题，恢复工作区时现已接受并校验完整的三份 config。
* 修复导入与编辑对同一条记账内容行可能出现语义不一致的问题，现已统一复用 `content_line_support` 解释金额表达式与注释边界。
